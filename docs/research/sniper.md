# 老练狙神

发射时查询原生动作脚本的 `IsPrecisionShoot` 状态，同一发射组及其弹体保留该状态。命中还需通过原生射击攻击类别105与实际伤害的检查。可在箭离手后松开瞄准。亮剑的抽取互斥和历史位42沿用。

发射时取角色脚下上方1.5米和当前水平面向。四箭按原生散射角飞出，飞行寿命4.4秒。前4米按发射角飞行，随后追踪实际命中敌人身上与命中点最近的可用锁定部位。部位由原生附件查询选出，保留原生锁定节点和动画中的点位。没有可用部位时取同一个敌人的通用瞄准点，敌人已卸载时按面向发射。

每轮按发射时的角色等级选择弹体与命中攻击参数。每支箭的基础魔力攻击力为当前版本未蓄力「罗蕾塔的绝招」的基础值加等级×10，随后走游戏原生伤害结算。

持有者的射程修正为bowDistRate=200、stateInfo=168。根弹体给射手附加0.6秒本机标记95004501，本机事件9101140以角色为声源播放一次放箭声（类型5，526261）。一次发射进入9秒游戏时间冷却。冷却中的精准射击和四箭命中各减1秒。冷却降到零后，下一次精准射击命中可触发发射。

原生命中回血词条 8600100 给攻击者施加 8600105，持续 0.3 秒。这里借用该持续时间作为持有者共享的减冷却间隔；同帧多弹、多目标和海克斯自身命中均受此间隔限制，间隔内的命中不刷新计时。
